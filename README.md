# Roguelike Game - DEMO для портфолио

[🇬🇧 English Version](README_EN.md) | [🇷🇺 Русская версия](README_RU.md)

Простая roguelike-игра, созданная на Python и Tkinter, демонстрирующая основные концепции разработки игр.

## Возможности

- **Процедурная генерация комнат**: Случайное создание нескольких комнат со стенами, полом и проходами
- **Перемещение героя**: Стрелки или WASD для перемещения героя
- **Обнаружение столкновений**: Стены блокируют движение, пол и предметы проходимы
- **Сбор предметов**: Собирайте золотые предметы (*), разбросанные по комнатам
- **Переход между комнатами**: Достигните выхода (E), чтобы перейти в следующую комнату
- **Визуальная обратная связь**: Отображение сообщений, количества предметов и текущей комнаты в реальном времени

## Управление

| Клавиша | Действие |
|---------|----------|
| ↑ / W | Движение вверх |
| ↓ / S | Движение вниз |
| ← / A | Движение влево |
| → / D | Движение вправо |
| R | Перезапуск игры |

## Легенда тайлов

| Символ | Название | Описание |
|--------|----------|----------|
| # | Стена | Непроходимое препятствие |
| . | Пол | Проходимая поверхность |
| S | Старт | Начальная позиция (зеленый) |
| E | Выход | Выход в следующую комнату (оранжевый) |
| * | Предмет | Сокровище для сбора (золотой) |
| + | Дверь | Декоративная дверь |
| ● | Герой | Игрок (зеленый круг) |


## Основные архитектурные решения

### Объектно-ориентированный дизайн
- **Hero**: Управляет позицией и перемещением игрока
- **Room**: Содержит данные поля и точки входа/выхода
- **GameField**: Обрабатывает процедурную генерацию нескольких комнат
- **Game**: Основная игровая логика, включая обнаружение столкновений и управление состоянием
- **Renderer**: Отделяет логику рендеринга от игровой логики

### Ключевые концепции
1. **Процедурная генерация**: Случайные планировки комнат с гарантированными путями
2. **Рендеринг на основе тайлов**: Сетчатая система карт
3. **Обнаружение столкновений**: Проверка свойств тайлов перед перемещением
4. **Управление состоянием**: Отслеживание предметов, комнат и прогресса игры
5. **Ввод, управляемый событиями**: Обработка клавиатуры для управления в реальном времени
